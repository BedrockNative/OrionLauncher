## 1.0.0

Orion 1.0.0 is a complete rewrite and the next official release after 0.5.0.

### Highlights

- **Minecraft GDK fully functional on Linux:** local skin selection, native Microsoft sign-in, servers, friends' worlds, world imports, structure import/export, and Marketplace purchases and downloads.
- **Multiple Microsoft accounts and independent instances**, with a fixed account per instance or automatic use of the launcher's current account.
- **Native Bedrock content management** for worlds, addons and textures, including imports, exports, shared packs and independent world copies.
- **CurseForge built into the launcher:** discover Bedrock addons, maps and textures, browse covers and versions, and choose where to install them.
- **More launch control:** per-instance arguments, environment variables and command wrappers such as `prime-run %command%`.
- **Integrated live logs:** a resizable terminal-style viewer, detachable per-instance windows, copy actions and automatic output following.
- **A new interface and architecture**, with extensive visual customization, complete themes, accent colors, wallpapers and immediately saved launcher settings.
- **Our own WineGDK fork**, giving the project more control over compatibility and performance, including fixes for minimizing the game or switching workspaces on desktops such as KDE.
- **RTX Studio:** browse BetterRTX presets, install RTX textures, import presets and configure ray-tracing launch preferences per instance.
- **Background instance installation**, resumable interrupted downloads, cancellation cleanup and a dedicated Downloads page.
- **Incomplete native binary modding removed.** A redesigned system is planned for the future; Bedrock addons, worlds and texture packs remain supported.
