# Maintainer avatars

Small public GitHub profile pictures, bundled for offline display in About.
These are profile images, not generated artwork. Retrieved on 2026-10-03:

- yPerfectBR: https://avatars.githubusercontent.com/u/109420964?v=4&s=128
- raonygamer: https://avatars.githubusercontent.com/u/75029692?v=4&s=128

The cards link to each maintainer's GitHub profile. To refresh a picture, replace
its PNG from the corresponding public avatar URL; no API token is needed.
There are no avatar network requests at launcher startup or when opening About.
