# Orion Launcher 1.0.3 — em desenvolvimento

## Instalação e atualizações

- Adiciona Latest Release e Latest Preview, com consulta de atualizações antes de iniciar. Prepara atualizações separadamente e recupera trocas interrompidas sem substituir mundos, prefixos ou configurações; mantém o jogo instalado quando o catálogo está indisponível.
- Compila LibXboxOne pelo submódulo XvdTool fixado para decriptar pacotes MSIXVC completos e extrair seu sistema de arquivos. Obtém chaves licenciadas pelo Xodus uma vez por conta/pacote na sessão do launcher e mantém o cache apenas em memória.
- Exibe blocos de decriptação e arquivos/bytes de extração com porcentagens. Valida nomes de arquivos e rejeita links no pacote.
- Gera MicrosoftGame.config ausente pelo manifesto do pacote. Inicia instalações completamente extraídas diretamente pelo Wine; mantém o caminho via CLI para instalações parciais antigas.

## Inicialização

- Adiciona Habilitar otimizações do Orion, desligado por padrão. Baixa Orion.Optimization pelas releases, prepara um executável separado uma vez e o reutiliza até o original mudar ou a cópia ser removida. Inicia o Wine diretamente, sem scripts intermediários gerados.
- Preserva o display Wayland original quando o GTK substitui o ambiente do launcher; configurações explícitas da instância continuam tendo prioridade.
- Mantém a saída normal concisa. ORION_DIAGNOSTICS=1 habilita tempos detalhados de preparação.
- Limita a espera pela saída dos processos após o jogo fechar e limpa prontamente a sessão Wine privada. Permite desligar o sistema sem o diálogo de fechamento manual.
- Preserva a janela maximizada/em tela cheia ao trazê-la para frente após erros.
- Mantém os serviços Xodus de outras contas ativos ao adicionar, selecionar ou remover uma conta.
- Remove o scaffold Orion.Native não utilizado e sua dependência no build/empacotamento.

Estas são notas de desenvolvimento. Esta alteração não publica uma release do launcher.
