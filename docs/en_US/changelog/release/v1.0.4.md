# Orion Launcher 1.0.4

## Installation and updates

- Fix installing Minecraft 1.26.62 and later, which failed with "The package must contain one Minecraft Bedrock GDK executable." These packages store `Minecraft.Windows.exe`, `MicrosoftGame.Config` and three images in NTFS records 16–23, which the extractor treated as filesystem metadata. Only the records NTFS reserves (0–15) are skipped now, and files marked Hidden or System are extracted as well.
- Add a Minecraft version choice to instance settings. Any instance can switch to Latest Release/Latest Preview or to a newer version of its own channel; older versions and the other channel are never offered. The update is installed the next time Play is pressed, using the same recoverable transaction as Latest updates, and keeps worlds, prefixes and settings.
- Instances tracking Latest Release or Latest Preview still check for and install updates of their own channel when Play is pressed.

## Logs

- Measured progress (downloads, decryption and extraction) updates a single log line in place instead of adding one line per step, and ends with the elapsed time for that step.
- Write installation events once when a game update runs inside a launch.

## Packaging

- Pin the AppImage type2 runtime rebuilt upstream on 2026-10-19 (commit `fedfad5`, SHA-256 `617aa773…`) after its `continuous` asset was replaced.
