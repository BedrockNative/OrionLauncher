# Orion Launcher 1.0.1

## Launcher improvements

- Added a persistent file manager selector in General settings: system default, Dolphin, Thunar, Nautilus, Nemo, Caja, PCManFM, PCManFM-Qt and Double Commander, with installed-application detection.
- All folder-opening actions share the selection, use literal path arguments and report launch failures. Portable bundle environment variables are filtered before starting host applications.
- Future draft changelogs no longer appear as published releases in older launcher builds.
- Desktop opacity changes now request confirmation inline instead of disabling the launcher behind a modal dialog; compositor validation and writes run off the UI thread.

## Documentation and contribution workflow

- Simplified the README with a feature roadmap, clearer WineGDK requirements and documentation links.
- Moved detailed issue reporting guidance into English and Portuguese documentation.
- Protected `main` against direct pushes, force-pushes and deletion; only same-repository `development` PRs pass the required source check.
- Added metadata-only routing of incorrectly targeted PRs and documented configuration merges without a version bump.
