# Orion Launcher 1.0.0

The next official release after 0.5.0: a completely rewritten launcher, a new interface and a native Minecraft GDK experience on Linux.

## Minecraft GDK and native Xbox services

- **Minecraft GDK fully functional on Linux**, including local skin selection, native Microsoft sign-in, joining servers and friends' worlds, world imports, structure import/export, and Marketplace purchases and content downloads.
- Native file selection and saving integrated with the desktop, without separate launcher-side file-picker patches.
- **Our own WineGDK fork**, giving Orion direct control over runtime compatibility and performance improvements.
- Fixed game issues when minimizing or switching workspaces on desktop environments such as KDE.
- Silent Wine prefix preparation, with startup diagnostics available in the instance log.
- A private Xodus profile and a dedicated `orion.xodus.sock`, alongside independent Wine prefixes, avoid conflicts with an existing system Xodus installation.
- Installation checks that a saved Microsoft account owns Minecraft for PC before downloading and decrypting it. Starting an already installed instance does not repeat that purchase check.
- Graphical system-keyring unlocking when needed, integrated into the sign-in flow.

## Accounts and instances

- **Multiple saved Microsoft accounts**, with account switching and removal inside the launcher.
- Xbox gamertags and profile pictures on account cards and selectors, plus a persistent current-profile indicator across pages.
- Choose a specific game account per instance, or follow whichever account is current in the launcher. Account selection and launch settings are available during creation.
- Independent instances with search, rename, recoverable archiving and optional Minecraft cover images; the lightweight, image-free style remains available.
- A unified instance-settings window groups general settings, launch options, environment, appearance and management.
- Per-instance Linux application-menu shortcuts are optional and disabled by default. Removing a shortcut does not remove the game.
- Tray and background operation, improved process supervision, and fixes for shutdowns that could leave Orion unable to reopen.

## Bedrock content library

- **A dedicated Content page** to manage local worlds, addons and textures, with `.mcworld`, `.mcaddon` and `.mcpack` import, export and recoverable archiving.
- A shared library can distribute content to selected instances. Addons and textures use symbolic links to a single source; worlds are always independent copies.
- Shared-library entries show pack icons, project names, content types and versions. CurseForge imports retain their project title; older entries named “download” display their pack metadata automatically.
- Pack cards show names, descriptions, icons, versions and minimum engine versions when available. Worlds show their saved name, last modification time and preview, with a monochrome fallback when available.
- User content stays separate from the game's internal vanilla packs. Validated imports, duplicate checks and recovery of interrupted operations help protect existing files.

## CurseForge

- **A dedicated CurseForge page for Bedrock addons, maps and textures**, available without first opening an instance.
- A discovery home with popular projects and covers, search, content-type filters, project information, file-version selection and pagination.
- Switching content type on the home loads that category automatically, discarding stale responses. Responsive project cards feature larger covers, aligned metadata and theme-aware hover/selection states.
- Install into one instance or the shared library, then distribute to selected instances using the same content-management flow.
- Respect author download restrictions: open the file's page in the browser and monitor Downloads or another selected directory. Completed files are verified before import, and the user's original download is preserved.
- Verified direct downloads and clearer network-error handling. Developers and custom builds can supply their own API key through an environment variable or private file.

## RTX Studio

- Native BetterRTX shader editor using the current site's versioned settings and compilation API, with categories, search and separate installation confirmation.
- Per-instance batch outcomes, `.rtpack` backups, optional `brtx://` handling and safe recovery of damaged or interrupted shader installations.
- Optional DLSS download from NVIDIA, trusted local DLL import and original-DLL restoration, independent of BetterRTX's deprecated DLSS endpoint.

- Browse BetterRTX presets with previews, search and game-version compatibility notices.
- Install presets per instance, import local `.rtpack` files and restore original shaders without overwriting the original shader files.
- Install Vanilla RTX, Normals and Opus texture packs from their latest stable releases.
- Per-instance launch preferences to request ray-traced graphics and optionally disable VSync.
- Recover interrupted shader changes and prevent conflicting game/content operations.
- Identify installed presets and texture packs, offer preset reinstallation, verify managed shader files and import local `.material.bin` files through the native BetterRTX-compatible workflow.

## Downloads, launch options and logs

- **Background instance installation** with a dedicated Downloads page and recent activity from the current launcher session.
- Resume interrupted instance downloads after a crash or forced exit; explicit cancellation cleans up partial installation files.
- Automatic discovery and verified installation of the latest supported runtime releases.
- **Per-instance arguments, flags, environment variables and command wrappers**, including `prime-run %command%`, without interpreting them as shell scripts.
- **Unified live instance logs** cover installation, prefix preparation, Xodus and the game in one terminal-style viewer.
- Wine crash backtraces and Minecraft content errors join the instance journal. Unhandled Wine exceptions are reported even when the launch process returns zero; supplemental crash files are referenced without copying private report contents.
- Resize the embedded log panel, follow output, copy logs or detach independent log windows to monitor multiple instances. Logs remain available on disk.
- An optional setting opens logs on Play, and a highlighted status bar makes game and task state easier to identify.

## New interface and visual customization

- **A complete rewrite**, separating domain, application, infrastructure and desktop UI responsibilities for a more maintainable codebase.
- A redesigned instance library, navigation, menus, dialogs, empty states and responsive content views.
- Complete Orion, Graphite, Grove and Dune visual themes, with matching surface colors, accent palettes, additional hues and custom RGB colors.
- Light, dark, system, scheduled and solar appearance modes, with independent light/dark preferences.
- Choose one static wallpaper or rotate images from a folder at a configurable interval, in random or sequential order. Adjust fit, blur, brightness and opacity.
- Theme-aware transparency across internal panels, menus and dialogs; optional compositor-specific opacity guidance and supported, consent-based exceptions remain separate from wallpaper settings.
- Sidebar or top navigation, reduced transitions, and launcher settings that apply and save immediately.
- English and Brazilian Portuguese UI, maintainer profiles in About, and bundled release notes readable offline.

## Removed and replaced

- **The incomplete native binary modding system has been removed.** A better-designed replacement is planned for the future. This does not remove support for Bedrock addons, worlds or texture packs.
- The proxy-based multiplayer path and launcher-side authentication, file-picker and DLL patches have been replaced by the native Xodus/WineGDK integration. Proton and UMU are no longer part of Orion's runtime flow.
- Automatic creation of instance application-menu entries has been replaced by an explicit opt-in setting.

## Important notes

- The GDK highlights above are not a blanket compatibility claim for every historical UWP client, GPU or driver. Minecraft ownership and any paid Marketplace purchases are still required.
- Resolution/fullscreen controls and active-monitor presets currently save preferences for a future implementation; they do not force the game's resolution or display mode.
- RTX requires compatible hardware, drivers, game versions and content. Installing a preset does not add ray-tracing support to unsupported hardware.
- Imported packs must still be enabled inside Minecraft. CurseForge dependencies are not installed automatically; world destinations require an existing in-game storage profile.
- Automatic download resumption applies to the instance-installation queue. CurseForge content and RTX transfers can be retried but are not part of that resumable queue.
