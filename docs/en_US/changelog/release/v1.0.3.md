# Orion Launcher 1.0.3 — in development

## Installation and updates

- Add Latest Release and Latest Preview choices that check for updates before launch. Stage updates separately and recover interrupted swaps without replacing worlds, prefixes or settings; retain the installed game when the catalog is unavailable.
- Build LibXboxOne from the pinned XvdTool submodule to decrypt complete MSIXVC packages and extract their filesystem. Fetch licensed content keys through Xodus once per account/package per launcher session and cache them only in memory.
- Report decryption block counts and extraction file/byte counts with percentages. Validate filenames and reject package links.
- Generate missing MicrosoftGame.config from the package manifest. Launch fully extracted games directly with Wine; retain the CLI path for older partial installations.

## Launch behavior

- Add Enable Orion optimizations, off by default. Download Orion.Optimization from its releases, prepare a separate executable once and reuse it until the source changes or the copy is removed. Launch Wine directly without generated wrapper scripts.
- Preserve the desktop's original Wayland display when GTK replaces the launcher's environment; explicit per-instance overrides still take precedence.
- Keep routine launch output concise. Enable detailed preparation timings with ORION_DIAGNOSTICS=1.
- Bound output draining after game exit and clean up the private Wine session promptly. Allow system shutdown without the manual exit prompt.
- Preserve maximized/fullscreen window state when bringing the launcher forward after errors.
- Keep other accounts' Xodus services running when an account is added, selected or removed.
- Remove the unused in-tree Orion.Native scaffold and its build/packaging dependency.

These are development notes. This change does not publish a launcher release.
