## Catálogo de versões Bedrock (Adicionar instância)

* **Estado de carregamento** enquanto as versões do jogo são obtidas, em vez de um combo vazio.
* **Painel de erro claro** quando o catálogo não carrega, com **Tentar novamente**, **Ver erro** e **Copiar erro** para relatórios de suporte.
* **Dica de timeout** no relatório copiável quando a falha parece expiração de rede (comum com IPv6 quebrado no Linux).

## Correções de rede (Linux)

* Os clientes HTTP passam a usar conexão **IPv4 primeiro** e **timeout de conexão de 30s**, evitando travamentos longos quando rotas IPv6 estão quebradas (ex.: `curl` funciona mas o .NET expirava aos 120s).
* **Fallback com curl no Linux** para o JSON pequeno do catálogo Bedrock quando o `HttpClient` falha por erro de rede transitório.
