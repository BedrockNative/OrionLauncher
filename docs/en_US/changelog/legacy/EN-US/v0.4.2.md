## Bedrock version catalog (Add instance)

* **Loading state** while game versions are fetched, instead of an empty combo box.
* **Clear error panel** when the catalog cannot be loaded, with **Retry**, **View error**, and **Copy error** for support reports.
* **Timeout hint** in the copyable report when the failure looks like a network timeout (often broken IPv6 on Linux).

## Networking fixes (Linux)

* HTTP clients now use an **IPv4-first** connect path and a **30s connect timeout**, avoiding long hangs when IPv6 routes are broken (e.g. `curl` works but .NET timed out after 120s).
* **Linux curl fallback** for the small Bedrock version JSON when `HttpClient` fails with transient network errors.

## Hub

* Fixed **“Call from invalid thread”** when refreshing Hub UI after navigation.

* README **troubleshooting** section for catalog failures, cache path, and `DOTNET_SYSTEM_NET_DISABLEIPV6=1`.
