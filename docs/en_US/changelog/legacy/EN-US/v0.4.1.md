## Instance Bedrock upgrade

* **Progress bar** and status text while an instance is updating in **Instance settings**.
* **Actions blocked during upgrade:** Back, delete instance, import mods, save LeviLamina version, and mod enable/disable toggles stay disabled until the update finishes (Open in file manager still works).
* **Player data preserved:** before replacing `game/`, the launcher backs up `Minecraft Bedrock/Users/` (worlds, addons, `options.txt`, etc.) to a temporary folder under the instance, then restores it after the new package is extracted. If the upgrade fails after the game folder was wiped, it attempts to restore from that backup.
* **After a successful update:** confirming the success dialog returns to the **Instances** list with the refreshed version on the card, ready to **Play** — the launcher no longer stays on settings or exit unexpectedly.

## Technical

* Centralized Bedrock player-data path via `BedrockGameLayout.ResolveUsersDirectory`; launch-time `options.txt` patching uses the same helper.
* Localized status strings for backup/restore steps (`en-US` / `pt-BR`).
